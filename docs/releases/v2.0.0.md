# TalentDesk v2.0.0 · 候选人开考前试答

发布日期：2026-11-23（中国标准时间）。本次大版本交付候选人开考前的试答和发送检查。

## 本次更新

- **开考前试答**。在候选人专属邀请页展开「开考前试答（可选）」，输入一段测试文字，点击「检查发送」。收到服务器响应后，页面显示「服务器已收到试答」。手机端和键盘均可操作。
- **失败后可重试**。连接失败时保留当前输入，候选人可在原页面重新发送。
- **正式作答独立计时**。试答不计分，不启动正式计时，也不写入正式答卷。候选人同意规则并正式开始后，服务端才开始计时。试答检查覆盖请求送达，正式答卷的保存仍由作答页的保存状态确认。
- **修复本地首页 404**。将项目检出在隐藏目录下时，已构建的工作台首页可以正常打开。

## 验证

- 生产前端构建、33 项服务端测试和 6 项浏览器测试通过。
- 新增浏览器回归覆盖手机尺寸、键盘操作、发送失败后重试、试答期间计时未启动，以及正式开始时答卷为空。
- [GitHub Actions 验证记录](https://github.com/Nevergoodstudy/AIhrsuperworkstation/actions/workflows/ci.yml)包含构建、测试和隔离容器备份恢复检查。正式服务器仍按部署验收流程签收。

## 升级与资料

从 v1.1.0 升级无需新增 SQLite 迁移或调整现有配置。沿用现有邀请和数据卷，按运维手册先备份并校验，在隔离副本检查邀请、试答、正式保存与提交，再升级目标环境。运行环境继续使用 Node.js 24。
