## 招聘阶段迁移规则

| 触发事件 | 允许的自动阶段变化 |
| --- | --- |
| HR 发起邀请 | 待筛选、待测评、待复核 → 待测评；记录邀请前阶段，归属本次考试。其他阶段保留 |
| 开始考试 | 仅本考试仍控制的待测评 → 测评中 |
| 提交或服务器超时提交 | 仅本考试仍控制的测评中 → 待复核，并解除归属 |
| 撤销或邀请过期 | 仅本考试仍控制的待测评 / 测评中，且有真实邀请前记录时，恢复邀请前阶段并解除归属 |
| HR 手动改阶段 | 使用版本检查，解除考试归属；考试可继续完成，但后续自动事件保留人工阶段 |
| 旧库归属未知 | 保留当前阶段，记录新发生事件，不推测或批量回退历史状态，由 HR 按实际情况调整 |

撤销、过期、提交分别保留独立考试状态。候选人删除会级联删除阶段事件与分析运行记录。阶段事件的页面时间线属于后续工作包，本次先保证可靠采集。

修复前已运行新增的 4 项 F1 / F2 测试和 13 项 F3 测试，分别 4 / 4、13 / 13 失败，捕获了原始问题；修复后全部通过。另新增 2 项旧库迁移测试，共新增 19 项后端回归。既有重启测试补充了中断分析恢复，既有招聘闭环、权限、计时、邮件、解析、备份及持久化测试均继续通过。

浏览器检查覆盖原有三角色完整流程与管理员改密，以及新增的：

3. 保存网络失败时退出保留本地文字；下载副本后可以退出。
