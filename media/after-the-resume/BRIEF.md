# 《简历之后》制作约定

目标：为 TalentDesk 招聘工作台制作可脱机双击播放的原创动态 HTML 短片。1920×1080，16:9，96 秒，80 BPM 的原创程序配乐。8 幕，每幕 12 秒。参考 Vibe 知识大赏的解释性图形、逐句字幕与形变衔接，不复制视频素材、品牌、文案或音乐。

主题：简历提供经历线索，任务产生可供复核的证据；AI 整理原文，人作判断。项目真实流程是岗位→简历→测评→人工复核→反馈。不得宣称已正式上线、自动录用、自动淘汰、算法公平保证、虚构效率或客户数字。

视觉：森林墨绿 #071b17、松绿 #173d33、薄荷 #b9f4d1、暖白 #f1eddc、浅金 #e4c18d、灰绿 #8fa99d。以纸张、标尺、证据连线、复核轨道和档案为主题；不做通用 SaaS 卡片轮播。标题 Songti SC / Noto Serif SC / serif；字幕 PingFang SC / Microsoft YaHei / sans-serif。画布字幕字号 44–48，图形小字至少 30。

时间表：
0–12：简历，能替你做决定吗？——简历、经历标签、尚未回答的问题。
12–24：经历，是线索。——文字经历变成可观察任务，区分描述与证据。
24–36：先约定，什么叫做好。——拆解问题、方案取舍、表达说明；人工评分要点。
36–48：让能力，发生在任务里。——专属邀请、任务作答、保存与提交。
48–60：让每个结论，都有出处。——原文与答卷连到复核，AI 整理，人工判断。
60–72：一次判断，需要共同复核。——多人独立复核汇合，由 HR 发布反馈。
72–84：业务能运行，也要能托付。——HR、部门、候选人分权；审计、备份与恢复。
84–96：简历之后 / BEYOND THE RESUME——流程汇聚为 TalentDesk，结尾留一个业务问题。

字幕只说明真实已有能力，不把图形示意当生产业务数据。最终 HTML 不请求外部网络、不嵌入候选人数据、无第三方追踪。播放、暂停、重播、拖动、章节选择、静音、字幕开关、全屏、键盘操作；减少动态偏好默认暂停。页面外控制区可有底部时间轴，成片画面无顶部进度条和常驻页眉。
